# Git Cheatsheet

| Command | What it does |
| --- | --- |
| `git clone <url>` | Download a repo to your laptop |
| `git checkout -b <branch>` | Create and switch to a new branch |
| `git status` | See which files changed |
| `git diff` | See exactly which lines changed |
| `git add <file>` | Stage a change |
| `git commit -m "msg"` | Save a snapshot |
| `git push origin <branch>` | Upload your branch to GitHub |
| `git pull upstream main` | Get the latest changes from the original repo |

Practise visually: https://git-school.github.io/visualizing-git/
