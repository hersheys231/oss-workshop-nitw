# Add yourself as a contributor

**Labels:** good first issue, first-timers-only

Create a new file `contributors/<your-github-username>.md` using `contributors/TEMPLATE.md`.

Rules:

- One file per person, named after YOUR GitHub username
- Don't edit anyone else's file
- Branch name: `add/<your-username>`
- Commit message: `docs: add <your-username> to contributors`
- PR description: `Refs #3` (not "Closes" — this issue stays open for everyone)

**Done when:** your PR adds exactly one new file.

No Git on your laptop? Fork → open `contributors/` on your fork → **Add file → Create new file** → commit to a new branch → open the PR.
